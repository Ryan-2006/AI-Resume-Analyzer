# AI Resume Analyzer

## Preview

![Project Screenshot](screenshot.png)

An AI-powered Resume Analyzer built using Flask and Python.

## Features

- Resume PDF Upload
- Email Detection
- Phone Number Detection
- Skill Extraction
- ATS Score Calculation
- Recommended Job Role
- Missing Skills Analysis

## Technologies Used

- Python
- Flask
- HTML
- CSS
- PDFPlumber

## Project Structure

AI-Resume-Analyzer
│
├── app.py
├── resumes
├── static
│ └── style.css
└── templates
└── index.html

## Installation

```bash
pip install flask pdfplumber
python app.py
```
